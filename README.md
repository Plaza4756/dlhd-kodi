## 🚀 **Quick Installation Guide**

### **Step 1: Add Repository Source**
1. Open **Kodi**
2. Go to **Settings** ⚙️
3. Select **File Manager**
4. Click **"Add Source"**
5. Enter this URL: https://plaza4756.github.io
6. Name it: `Plaza4756` (or any other name)
7. Click **OK**

### **Step 2: Install from Repository**
1. Go back to **Home Screen**
2. Select **Add-ons** 📦
3. Click the **Package Installer** icon
4. Choose **"Install from zip file"**
5. Select **"plugin.video.dlhd.x.x.zip"**

**Done!** Enjoy DLHD in Video Add-ons section.
